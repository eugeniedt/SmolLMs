# Welcome to SmolLMs, WS26/27 edition! 

This is a course by Eugénie Desmedt and Magdalena Samonigg for the Bachelor Students of the Art x Science School for Transformation during the Winter Semester 26/27. Together, we will fine-tune our own little languge models on the basis datasets we curate and create a simple web-based interface for them on our own hardware. We will examine what it means to generate synthetic text, observe available tools through a critical lens, and familiarise ourselves with open-source and open-weights practices and platforms.

## Course environment setup

This course uses Docker and VS Code to provide a consistent  programming environment. We will write code with Python in Jupyter Notebooks for the first part of the course, and HTML, CSS and Javascript for the second part. Here's how to get started: 

Install from the internet:
- VS Code
- Docker Desktop

For Docker, take care to install the correct version for your OS. 

Also install the VS Code extensions:
- Dev Containers 
- Python
- Jupyter

Download from Moodle (or GitHub): 
- SmolLMs course folder

To open the course environment: 
- Start Docker Desktop. You should see (in the lower left corner): "Engine Running"
- Open this course folder in VS Code.
- When prompted, click "Reopen in Container". If you do not see the prompt: View -> Command Palette -> "Dev Containers: Reopen in Container"
